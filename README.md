# Retro Diner - Accessibility Audit & Remediation (WCAG 2.1 & Silktide)

## Deliverable URL
- **GitHub Pages (Live URL):** https://jjonathan27.github.io/retrodiner/
- **Repository:** https://github.com/jjonathan27/retrodiner

---

## Summary of Accessibility Issues Identified & Fixed (Silktide Analysis)

| Category | Issues Found in Original Site | Fixes Implemented |
| :--- | :--- | :--- |
| **1. Alt Texts (`<img>`)** | • Header & footer logos (`logo.png`, `logo-footer.png`) had empty `alt=""` inside links, leaving links with no accessible name.<br>• Waitress illustration (`waitress.png`) lacked an `alt` attribute altogether and had a stray `</a>` tag.<br>• Promotional and menu images (`burger-specials.png`, `hotdogs.jpg`, `shakes.jpg`, `breakfast.jpg`, `burger.jpg`, `hotdog.jpg`, `shake.jpg`, `breakfast2.jpg`, `breakfast3.jpg`, `shakes2.jpg`) had empty `alt=""`. | • Added concise, context-appropriate `alt` text to every `<img>` across all 8 pages.<br>• Functional image links (logos and menu promos) now describe the destination (`alt="Retro Diner Home"`, `alt="Burger Specials promotional banner: view our burger menu"`, etc.).<br>• Cleaned up stray `</a>` and malformed `<a img src="shake.html">` tags. |
| **2. Keyboard Checks (Focus Order & Focus Visible)** | • `css/style.css` had `a { outline: 0; }`, completely removing keyboard focus indicators (WCAG 2.4.7 failure).<br>• No "Skip to main content" link.<br>• In `blog.html`, the date badge `<a class="price">` was placed at the end of each post in the DOM but visually positioned at the top-left (`position: absolute; top: 0; left: -100px`), causing keyboard focus order to jump backward. | • Removed `outline: 0` and added high-contrast `:focus` / `:focus-visible` outlines (`3px solid #ff4500` on light surfaces and `3px solid #ffea00` on dark teal header/footer).<br>• Added a keyboard-accessible `<a href="#body" class="skip-link">Skip to main content</a>` as the first interactive element.<br>• Fixed DOM order in `blog.html` and removed redundant self-links so tab order strictly follows visual reading order. |
| **3. Headings Hierarchy (`<h1>`–`<h3>`)** | • `index.html` and `blog.html` had no main `<h1>`.<br>• `burger.html`, `hotdog.html`, `shake.html`, and `breakfast.html` had two `<h1>` tags (`<h1>Burgers</h1>` and sidebar `<h1>Menu</h1>`).<br>• `contact.html` had five `<h1>` tags and skipped from `<h1>Contact</h1>` directly to `<h4>`.<br>• Footer used `<h3>Call 0-123-456-789</h3>` for a phone number. | • Enforced a strict, single-`<h1>` hierarchy per page without level skips (`H1 -> H2 -> H3`).<br>• Converted sidebar titles from `<h1>` to `<h2>`.<br>• Fixed `contact.html` subheading from `<h4>` to `<h2>` and removed duplicate "Open Everyday" block.<br>• Converted the footer phone number from `<h3>` to `<p class="hotline"><a href="tel:0123456789">...</a></p>`. |
| **4. Regions (Landmarks)** | • Entire layout used generic `<div id="header">`, `<div id="body">`, `<div class="sidebar">`, and `<div id="footer">`, resulting in zero HTML5 landmarks in Silktide. | • Replaced generic wrappers with semantic landmarks across all pages:<br>  - `<header id="header" role="banner">`<br>  - `<nav aria-label="Main Navigation">`, `<nav aria-label="Menu Categories">`, `<nav aria-label="Footer Navigation">`<br>  - `<main id="body" role="main">`<br>  - `<aside class="sidebar" aria-label="...">`<br>  - `<footer id="footer" role="contentinfo">` |
| **5. Document Language, Forms, Links & Contrast** | • Missing `<html lang="en">` and `<meta name="viewport">`.<br>• Social media links (`a.facebook`, `a.twitter`, `a.googleplus`) and `.download` button had no text or `aria-label`.<br>• Newsletter email input had no `<label>`, and submit buttons (`<input type="submit" value="">`) had no accessible name.<br>• Main navigation links had intentional low contrast (`#4D8D93` on `#1B6568` = `1.78:1` and `.active` `#822619` on `#1B6568` = `1.39:1`). | • Added `<html lang="en">` and responsive viewport meta to all 8 pages.<br>• Added `aria-label` and `.sr-only` text to social icon links and download buttons.<br>• Linked newsletter input to `<label for="subscribe-email" class="sr-only">` and added accessible names to submit buttons.<br>• Updated navigation link colors to `#ffffff` (`6.76:1`) and `#ffea79` (`5.45:1`) on `#1B6568`, and body paragraph text to `#4c1407` (`14.89:1`). |
